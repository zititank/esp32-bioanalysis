# Documentation workspace

This repository separates source-material extraction from project-specific
interpretation:

- [`parsed/`](parsed/): factual, structured notes extracted from papers,
  datasheets, standards, and other sources. Keep interpretation minimal.
- [`studied/`](studied/): reading notes that connect sources to the proposal,
  identify limitations, and record questions for the team.

Use one Markdown file per source. Include the source title, authors/year, DOI
or URL, date accessed, and a short list of open questions.
