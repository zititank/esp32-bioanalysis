# Studied documents

Store project-facing reading notes here. Each note should make clear:

- what the source supports or contradicts in the proposal;
- which claims are directly measured versus inferred;
- what should change in the experiment, analysis, or safety plan;
- which questions remain unresolved.

Keep the project's fixed hypotheses fixed. New evidence should lead to a
documented follow-up experiment or limitation, not a retrospective rewrite.
